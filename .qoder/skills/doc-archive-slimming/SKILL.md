# 待办归档瘦身（工作法）

> 承接自 WB 同名技能（2026-10-13 执行权移交 Qoder），非原文复制；坑与判据按 Qoder 侧实操补写。
> 适用：把 `TODO.md`（或等价待办文件）里已闭环的阶段整块冷存进 `archive/roadmap-history.md`，目的＝**控制待办文件规模**。
> ⭐ **变体：迁 `docs/` 而非 `archive/`（2026-10-19 实操立）** —— 段里装的是**仍活跃的规矩／判据**（不是完成态快照）时走这条：性质 ＝ **消重**（多半 docs 早已承接，实测 7 项里 5 项）＋ 补缺口 ＋ 修指针，⛔ 不是搬运。纪律全同，两处改口径：① 〈二·4〉「插在编号位」→ **落该规矩的既有权威节，⛔ 不新开创则**（实测「同一环境只用一个 DSH home」落 `production-env.md` §12.7 附一 —— 那节本就在讲"两个 home"的成因与处置）；② 〈一·2〉「逐字迁出、零改动」只约束**归档区**，迁 `docs/` 时允许形态适配（复选框 → 规范条文），但**带引号的直接引用与否定式口径必须逐字**（程序化 assert 两侧同形）。

## 一、核心纪律（缺一即返工）

1. **只搬「块内 `[ ]` = 0」的块**，且**程序化核**（脚本数，别肉眼）。整段标 ✅ 但块内仍含 `[ ]` 的**不搬**——那是状态标记过期或真实在飞项，见〈doc-governance-recheck〉第四条。
2. **正文逐字迁出、零改动**：归档区是**锁定快照**，不进讨论、不勾状态、不就地更新。
3. **归档一次成形**，不分几次进——分次会在锁定区留半截块，后续没人能判断它完整过没有。
4. ⭐ **收件判据是「是否仍被引用」，不是「是否闭环」**。判据类内容若仍活跃：**先落 `docs/` 再搬**。直接搬＝把活跃判据埋进冷存，且原块那句「权威落点 = docs」会变成空指。
5. ⭐ **正确顺序：先归位（判据 → docs）→ 再落位（未决 → TODO）→ 后搬家（TODO → archive）**。颠倒会把未决项冻进快照里。
6. ⚠️ **别信原句的「各有归宿／已登记」断言**——逐条 grep 验证。实例：某段自述「3 项各有归宿」，核下来只有 1 项真落到别处。

## 二、流程要点（顺序即检查表）

1. 读目标区 README（分区规则）＋ 待办区顶部治理约定。
2. `git status` —— 确认无他人正在改这两个文件（共享工作区）。
3. 按标题切块（含块末空行），**切前 assert 首末行内容**（他人刚改过会静默切错，且切错会一路带到底）。
4. **插在编号位，不追加文末**——冷存文件多按阶段编号排序，文末追加会破坏其目录语义。
5. 段头补四要素：阶段身份 ／ 冷快照声明 ／ `:N` 坐标系说明（本文件行号 vs `file:N` 文件行号）／ 迁出来源 ＋ 一句「未决项不载于本段」。
6. 补该区目录／索引行；TODO 侧留**指针**（⛔ 指针里不放 `[ ]`，否则又造出假未决项）。
7. 修引用（见第三节）→ 校验（第四节）→ 合并 commit（用明确 pathspec，不 `add -A`）。

## 三、引用修复（两个方向）

- **区外 → 被搬块**（借地址）：必须改指；仅提及（不依赖其坐标）可留。⚠️ **同名陷阱**：扫 `3.0` 会命中另一份文档的 `§3.0`——先核目标**当下在哪**再改。
- **块内 → 区外**：**段头写一次坐标系说明**，不逐条重算行号。先分清裸 `:N`（本文件行号）与 `name.ext:274`（文件名行号）。
- 顺手清算早已腐烂的 `:N`：判据＝打印该行当下内容，跟引用语义对一遍；修法＝**改指段名／条目名**（跨会漂移的行号引用是持续失活的源头）。

## 四、校验六项（全过才算完成）

1. **零越界删除**——用**多重集差**（行内容可重排），⛔ 不用 `numstat` 判（位置化 vs 位置无关，对不上多半正常）。
2. 待办侧**未勾选数不变量**：搬前后 `[ ]` 计数符合预期（只减被搬块内的量）。
3. **✅ 段内不得含 `[ ]`**（一致性不变量，程序化）。
4. **内容不丢**：块正文逐段 `in` 归档新文本。
5. **全仓引用跨文件扫描**（`.md`／`.ts`／`.py`／`.sh`，不只文档区）。
6. **凭据扫描**：`Bearer|password|secret|sk-` 命中即停手上报（Tier 0 红线）。

## 五、坑登记

- 中文别用 `cut -c` 切；含反斜杠／正则的脚本写成 `.py` 文件再跑（shell 内联会吞转义）。
- 归档后**反向 grep 旧落点**（详见〈doc-governance-recheck〉），确认没有残留引用指向已搬走的坐标。
- 「某段已收口」是**带时间戳的断言**：其后任何段外新增都会让它过期，别再当现态陈述引用。
- 跨文档引用优先用**章节锚／条目名**，不用 `:NNN`（本次实操教训：行号在当时快照正确，仍会随他人编辑漂移）。
- ⭐ **Windows Python 的 stdout 是 GBK**：脚本 `print` 带 `⇒`／`⛔`／`⚠️` 会 `UnicodeEncodeError`，且**常崩在写盘之后** ⇒ 看着"失败"、实则文件已改（实测 `save()` 已落 9+/3−，崩在其后那一行 print）。规矩：① print 只用 ASCII，或跑时加 `PYTHONIOENCODING=utf-8`；② **见到 exit≠0 先 `git diff --stat` 核是否已落盘**，⛔ 不盲目重跑（重跑有"旧文本恰命中 1 次"的断言兜底，但先核一眼更省事）。
- ⭐ **「旧文本已消失」类断言，⛔ 别拿自己新写的文本当关键词**：实测写 `assert '贯穿规则' not in t`，而替换进去的新文本自带一句「（原写「`TODO.md` 贯穿规则」，本日已迁出）」的历史注记 ⇒ **自造假红、拦下自己**。规矩：消失性断言用 **OLD 整串**（`assert OLD not in t`）；要限次数就 `assert t.count(词) == 期望值`。
- ⭐ **同一矩阵／清单的两份副本，措辞会各自漂移** ⇒ 逐字比对必假红。实测同一条负向对照四处不同：待办侧「换错 Key」／文档侧「换**成**错 Key」、「摘/只读」vs「摘掉 / 只读」、「kill SDK 客户端」vs「…客户端**进程**」、「停 ChromaDB」vs「停 ChromaDB **进程**」。规矩：跨副本核承接用**核心词**（剥掉易变前后缀），⛔ 不用整条；迁完只剩一份 ＝ 顺手消除漂移源（别家 skill 那条"改措辞前先全库 grep 副本"的教训随之减半）。
- ⭐ **压规模类动作，收尾必量字节、⛔ 别只看行数**：实测段本体 4478 → 2539 B（−1939 B），但**办结登记 +670 B、追加转报条 +1016 B** ⇒ 待办文件净减只剩 **550 B**（0.8%），行数 287 → 282。规矩：① 每步跑完 `wc -c` 前后对账；② **办结登记压到一行**（只留：办结事实／处置性质／落点／对原登记的订正），过程细节走 git 史与自家 log；③ 净收益与预期差一个量级时**如实报**，⛔ 不拿"行数减了"充数。
- ⭐ **别人登记的量化口径要自己重量**：实测待办里那条登记写「本文件 `:114` 起 **173 行**」，真段只有 **19 行**（`:114–132`）—— 173 ≈ `:114` 到**文件末**的行数。规矩：接「迁某段」的活，第一件事是 `assert` 段的**首行 ＋ 末行 ＋ 下一节标题**三个锚点、自己量边界，⛔ 不采信登记里的行数（它会一路带偏你对收益的预期，也会让你把"19 行"的活当"173 行"排期）。
- ⭐ **核心纪律 1 的实操补充：「块内 `[ ]` ≠ 0 就不搬」之前，先分辨那几个框是哪一种**。实测待迁段含 4 个 `[ ]`，逐条核下来**全是"规矩"而非"任务"**（负向对照矩阵／姿势自证／环境口径统一／参考件先行 —— 从来不是可勾完的事，是持续遵守的约束）⇒ 属**状态标记过期**，摘框 ＋ 落 `docs/` 规范是正确处置。⚠️ 但"过期"⛔ 不得靠推理认定，**要找物证**：判据 ＝ 去冷存区搜该规矩在各切片的兑现记录（实测 `archive/roadmap-history.md`「DSH-3.1」段有「负向对照 3／4 补"破坏动作生效"锚 —— 已补 ＋ CVM 实跑验证」＋ 一条过度声明订正 ⇒ 🟢 兑现）。**找不到物证 ⇒ 按真实在飞项处置**（保留 `[ ]`、只更新内容或转 backlog），⛔ 不删。
- ⭐ **代码注释也是引用面**：校验第 5 项扫 `.mjs`／`.py` 不只是形式——实测扫出 `harness/scripts/run-s0-e2e.mjs:38` 注内写「统一到项目口径（`TODO.md` 贯穿规则：…）」，段一迁走即失活。规矩：按〈doc-governance-recheck〉二·3 判别（指向**文档坐标**才改，指向**物自体**不修）；⛔ 代码非 Qoder 可写区 ⇒ **登记转报给 Trae**，并附「建议改法 ＋ 脚本行为本身是否需改 ＋ 一行可复算判据」（如 `grep -n "TODO.md" <该脚本>` 零命中）。
