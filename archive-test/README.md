# 归档区（archive/）

冷存储归档——放历史路线图、事故复盘报告、已完成阶段的快照。只复盘、不追加、不追踪现态。

- 本区域由WB进行维护（主要涉及已完成任务的归档）
- 复盘报告一般不做修改，对于一些已经明显对工作开展产生负面影响的文档记录，AI进行主动暴露，由老大进行裁决并亲自修改
- 特殊情况下，老大可以直接对本区文件进行干涉

## 规则

- 本区文件是**定稿快照，已锁定**：不追加讨论、不勾选状态、不就地更新。
- 报告中的「待办 / 未闭环」均为当时的历史陈述；**未决事项一律以 `TODO.md` 为唯一事实源**，本区不追踪现态。
- 有新发现记入 `exchange/` 活日志或新建报告，不改老报告。
- 排查 BUG / 做改动前先扫 `roadmap-history.md`（历史路线图）。
