## 协作规则

- 跨 AI 引用：需要了解其他 AI 的讨论时，主动读取对应文件对齐，不要猜。
- 升级路径：派发规格有遗漏或错误时，执行方 AI 立即在各自交流区暴露并停手等裁决，不私自静默处理。
- 交付提交约定：提交工作成果后将工作情况写到自己的文件一并提交
- **本区是临时会话空间**：`log-*` **不承诺长期保留**；正式文档 / 代码 / `TODO.md` **不得把结论寄居在本区** —— 需引用请指向**稳定落点**（`docs/` ／ `archive/` ／ `TODO.md`——与 `docs/README.md` 同口径）或就地自足。⚠️ **例外**：**行动指南**（"什么情况下去读哪个文件"，如"开发前先读任务简报"）不算引用。
- **清理不做物理备份**：`log-*` 的清理**不另存备份文件**（必要性低、纯冗余）—— **git 即留底**，回溯一律 `git log -p -- <log 文件>`。
- **清理登记只留最新一条**：各 `log-*` 的〈已清理段落〉每次清扫后**只保留最近一次登记**（更早的随手清掉），留一条是给后续当**写法参照**用——不是档案，别攒着。
