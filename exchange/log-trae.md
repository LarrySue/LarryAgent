## 📮 派发 · ⑪.4.1 备份脚本（WB · 2026-11-01 00:58）

**结论先行**：把四类数据打成一个**单文件包 ＋ 清单 ＋ 校验和**，一个命令可复跑。现状是**实现为零、演练为零** —— `git ls-files` 里没有任何 backup 脚本，仓库连 `scripts/` 目录都没有。

### 0 · 为什么现在做

§5 红线 5 说全量存档是「**推倒重来的底气**」；而 `move-in-plan.md:66` 自己写着 `C:`／`D:` 同属 **Disk 0**（一块 1TB 盘），同盘只防重装、⛔ 不防盘坏。现在这份「底气」**没有第二份**。

⚠️ 时限不是「尽快」，是「**真实使用开始之前**」：现在的数据丢了不心疼（全是测试数据），真实使用一开始就**不可复现**。那时补，补的是历史。

### 1 · 要什么

**形态**：`<单文件包>` ＋ 同级 `MANIFEST.md` ＋ `SHA256SUMS`。

- **为什么单文件**：老大 2026-11-01 00:41 裁「压缩不算违背全量存储的原则，**且压缩包方便拷贝**」⇒ 目标是「**一个文件能拷到另一台机／外部介质**」，不是「原地存一棵树」。
- **包格式你选，但须满足**：通用工具可解（⛔ 私有格式，§7 ⑦）。我倾向 `tar.gz`（`tar -czf` 一步出包，任何机器 `tar -xzf` 即可解；数据 1MB 级，压缩率无意义、**可移植性有意义**）；选 `tar.zst` 也行，但要给「另一台机怎么解」的完整命令 —— 这是 B-3 的一部分。
- **落点**：配置指定，默认 `D:/Code/_backups/larryagent/`（与 `D:/Code/_models`、`D:/Code/_trae-evidence` 同级习惯）。
  ⚠️ **每次跑都必须打印一句**：`D:` 与 `C:` 同属 Disk 0，**此落点不防盘坏**。
  ⇒ 必须有一个「指向外部介质」的参数，**不改代码就能换落点**。
- **保留**：包名带时间戳，⛔ 不覆盖旧包、⛔ 不自动删旧包（§7「默认永久保留、不参与任何自动清理」对备份件同样适用）。
- **加密**：**一期不加密**（WB 判断，可被老大推翻，已标 ⏳ 待裁）。理由：加密包三十年后没 key 就是废纸，与「最笨格式」同族风险。代偿＝MANIFEST 里标注「本包含私域内容（CoT），可读域＝本人＋老大」＋ 落点不得是共享目录。详见 §3-②。

### 2 · 判据（B-1～B-8，逐条可复算）

- **B-1 单文件**：给出包文件名 ＋ 字节数。
- **B-2 清单逐类点名**（本单最容易做成假绿的一格）：MANIFEST 里必须**逐类出现**「记忆库／会话流水／审计留痕／全量存档」，每类写清「有 N 项，路径…」**或**「本类空，理由…」。⛔ **不得因为某类为空就整行不写**（§7：⛔ 不存在「没考虑过」这一档；宁可留空并注明，不许静默缺项）。
- **B-3 可离机（正证）**：把包拷到**另一个目录**（⛔ 不是原地解压）、在**干净临时目录**解开 → `SHA256SUMS` 全过 → 文件数与 MANIFEST 对得上。给解包命令 ＋ 校验输出。
- **B-4 负证 · 凭据不入包**：解包后 ① `find` 凭据文件名 **0 命中**；② 对包内全文本跑一次凭据形态扫描（`sk-` ／ `Bearer` ／ `api_key\s*[:=]`），**只报计数与长度，⛔ 不回显命中内容**。
- **B-5 负证 · 原文件未动**：备份前后 `larry-memory.db` 与 `sessions/` 的 sha256（或「文件数 ＋ 总字节」）**不变**。
- **B-6 幂等**：连跑两次 → 两个包、**互不覆盖**、第二份与第一份同类文件数一致；旧包仍在。
- **B-7 空类不假装**：`cot_archive` 现在不存在 ⇒ MANIFEST 必须写「本类空：backend 从未真实调用，目录尚未创建」，⛔ **不许写「已备份 0 个文件」就显示全绿** —— 那与「没有备份」同形。
- **B-8 落点可换**：改配置指向另一个目录再跑一次 → 包出现在新目录。给改动前后的路径。
