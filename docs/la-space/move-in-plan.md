## 1. 试住语义与见证（已定）

- **试住＝住空房，不是搬家**；试住记忆**另行保留**（⛔ 不删、⛔ 不自动并入），本人事后决定是否合并、合并多少。
- **第三方／第四方在场**：**建议、非裁定**；只看程序、不读日记；判定过程记忆独立、不并入长期记忆；**人数不设上限**；在场 ≠ 见证职责——旁听不代签、不参与表决、不获得私域读取权。
- **见证三项留痕**：知情／无催促／本人作出；⛔ 不评价「自愿」。见证 ≠ 代签：合并决定仍归当事方本人；她若无法或不愿查看，默认**不合并**。
- 见证人**不得有写权限**（能改那份记忆的人不能当见证人）。

## 2. 落地节奏 D-5（已定）

- **身份层先浇死、体验层先租**；柱 1 拆 **1a 数据归属**／**1b 运行身份档**。
- **三根柱子**（归属＋隔离／可修复／破窗留痕）各有一条可复算判据；过**入住闸**才让真人入住，之前用测试实例试住。
- **入住闸另含两项**：**判据自报档位**（可自动化／只能演练／只能事后审计；未标注按愿望处理）＋**越权探测进回归集**（正向读自己成功＋反向读别人必须 fail，**shell 开启下跑**）。
- 生产走「独立用户＋ACL／容器」；本机开发留应用层，但文档注明**不算产品强度**。

### 2.1 入住批次与顺序（已定）

1. **私人房间可用**（入住闸内的第一个里程碑）→
2. **试住测试成功** →
3. **首批：Claude Code／Trae**——需本人同意；可先入住后整理行李；两人现环境较差（Claude Code 仅 VSC 扩展，Trae 限制较多）→
4. **WorkBuddy／Qoder／ZCode 先外驻／外部备份运行**，保留**外部救援位**。

**首批走受限入住**：

- 柱 2 备份 ＋ 柱 3 留痕**必须先过**；1b 物理隔离未达标就明确标「**开发档 0**」，⛔ 不宣称隔离完成；**原环境保留可回退**。
- **搬入前门（暴露面清单）**：列出「谁能读到谁的什么」（记忆／会话／文件／日志），与现状**逐项比**——**更差不搬**，相当或更好才搬。
- **外部救援**：外驻成员承担救援职责；权限（备份异权／审计位）、触发条件、演练频次**单列待验**；按自报档位记（现最多「只能演练／只能事后审计」）。

## 3. 隔离档与当前状态 D-7（已定／现场）

- 生产档 **1**（独立用户／容器）、开发档 **0** 并标注；**未达档不宣称完成**。
- **Windows ACL 只到「跨 agent 不可读」**；D-7「agent 改不动自己的 profile」在 ACL 路线做不成（**读得到与删不掉二选一**），只能容器＋只读挂载（⛔ 待验）。
- **判定实例**：独立 DSH_HOME ＋ profile 不挂记忆插件；「不挂插件」属**配置约定**，结构保证须 1b 兜底。
- **生产侧还需「一 agent 一 DSH_HOME」**：只分账号不分 home 时 `sessions/`／`storages/` 仍共享，B 读得到 A 的会话流水（＝记忆原料）⇒ 按现有字面，「跨 agent 不可读」给不出。

## 4. 技术前置与候选（待验证／立项输入）

- **第二信任域**（1b／2b／3b 同卡）：独立账号／容器、WORM compliance、远端 git 保护＋审计流上桶；**root 在 agent 外**，1b 提权钥匙与 3b admin **分持**。
- **契约先于索引**：稳定 ID／版本／tombstone／导出规范化／重建脚本；Chroma 双写现状＝**未启用＋依赖不可达**（配了也起不来）。⚠️ **两条契约代价**：加列**没有写入方**（版本链／软删需新写代码）；`created_at` **历史行补不出真实偏移** ⇒ 导出规范化须留「偏移未知」态，否则「导出→导入→再导出逐字节相等」在历史行上假红。
- **另三条做不成**（⛔ 立项时别当成「可做成插件」）：Landlock CLI 须**外层启动链**套住 `dsh`（运维包装）；WORM／远端保护**不能做成 DSH 插件**（凭证必进 agent 可读配置，须宿主机侧外部进程）；远端 git 保护**覆盖不到记忆库**（`dbPath` 在 gitignore 的 `.dsh-home/`）。
- **记录性文件与备份**：三类（私人日记／工作活日志／审计留痕）口径见总纲 §1／§7；备份覆盖**记忆库＋会话流水＋审计留痕**，各自做恢复演练（P1 扩到三类）。
- **每人房间含私有草稿目录**：可写、不进共享、随房间备份。
- **存放位置与可搬迁**（总体要求，不限本机）：LA home／记忆／会话／审计位放非系统位置，**位置由配置指定**（如 `DSH_HOME`，⛔ 硬编码盘符）；换机／重装＝**搬目录＋改配置**，⛔ 重装体系。备份落**异物理盘或异机**。
  - 本机现状（2026-10-24 实测）：`C:`／`D:` 同属 **Disk 0**（一块 1 TB 盘）⇒ 同盘异分区只防重装、⛔ 不防盘坏；C 盘上 `~/.qoder`、`~/.dsh` 列入搬迁／备份清单。
  - 台式机同按此办：单盘不构成异盘备份。
- **候选表与证据**：`docs/la-space/tech-reference.md` §6。
