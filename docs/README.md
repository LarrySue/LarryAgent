# 文档区（docs/）

活跃权威文档的存放地——放"定案 / 单一真相源"级别的文档，仍被代码、测试、多 AI 引用，作为协作时的最终依据。

- 本区域无特殊情况不可修改，对于一些已经明显对工作开展产生负面影响的文档记录，AI进行主动暴露，由老大进行裁决并亲自修改
- 特殊情况下，老大可以直接对本区文件进行干涉

## 落位标准

| 状态 | 去向 |
|---|---|
| 活跃权威（仍被代码 / 测试 / AI 引用） | `docs/`（本区） |
| 冷历史（仅复盘，不再被引用） | `archive/` |
| 草案 / 讨论稿 / 过程记录 | `exchange/`（定稿后回本区） |

## 与交流区的关系

- 本区是"定案级"，交流区（`exchange/`）是"过程级"；两者冲突时以本区定案为准。
- 单份文档内部的权威层级（如 UI 的"代码数值 > 设计定案 > 过程讨论"）由各文档自述，不做全区统一。

## 文件索引

- `ai-governance.md` — 多 AI 协作约束分级总纲（Tier 约束模型、角色分工、协作规则）
- `ui-reference.md` — UI 设计单一权威参考（组件 / 交互 / 视觉 token，所有 AI 以它为准）
- `web-search-design.md` — 网络搜索技术选型与设计规格
