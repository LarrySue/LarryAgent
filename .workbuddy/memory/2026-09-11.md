## ⚠️ 工具层教训：同一文件的并行 Edit 会互相覆盖

- **现象**：对**同一个文件**发起多个 `Edit` 调用（同一消息内并行），返回值均报 success，但**只有最后一个落盘**，其余静默丢失。本次实测：README 的三个并行 Edit，仅第 3 个生效；migration 的两个并行 Edit，仅第 2 个生效。
- **成因**：并行 Edit 基于同一基线快照，后写整文件覆盖前写。
- **纪律**：**同一文件的多个 Edit 必须串行**（一次一个，等返回后再下一个）。跨不同文件的 Edit 可并行。
- **验证手段**：改完后**必须 Read 磁盘复验**，不能只信 Edit 的 success 返回。
