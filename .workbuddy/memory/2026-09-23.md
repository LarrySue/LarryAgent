### 关键发现（四条）

1. **`bwrap` 不存在，且"装上"这条路也堵死** —— 不仅 `dpkg` 未装；`apparmor_restrict_unprivileged_userns=1`（Ubuntu 24.04 默认）⇒ 实测 `unshare --mount` ／ `--pid` ／ `--user --map-root-user` **全 FAIL**（`Operation not permitted`），仅不带映射的 `--user` 可用。bwrap 依赖 mount ns ＋ userns 映射 ⇒ **装上也起不来**。⇒ 该前置从「装不装」升级为**要不要放开主机级 AppArmor**（`sysctl kernel.apparmor_restrict_unprivileged_userns=0`，需 root）的架构取舍。
2. **landlock 正证通过** —— `python3` ctypes（与 DSH 互为独立通道）：ABI=**4** → `PR_SET_NO_NEW_PRIVS` OK → `create_ruleset` OK → `restrict_self` OK → 读 `/etc/hostname`、`/etc/os-release` **均 `EACCES`** ⇒ 内核真实强制（不是"建了规则集就算"）。
3. **ABI 4 的精确语义（读源码定死）** —— `node-addon-system/src/main.c`：`MAX_ABI 5L`（`:94`）；`*partial = abi < MAX_ABI`（`:237`）⇒ CVM ABI=4 ⇒ **`partial`**（probe 打印 `landlock: partially enforced (older ABI)` 且 **exit 0**，是"降级接受"不是 fail）；掩码按协商 ABI 裁剪（`:184-189`）；ABI4↔5 差距 = `LL_FS_IOCTL_DEV` 一位（`:85` 注：ABI 4 只加 TCP 位）。
4. **fail 形态 = fail-closed** —— `main.c:23-28`：建不了 ruleset ／ 内核不强制 ⇒ **`exit 125` 且不 exec**；`dsh-sandbox-local/README.md:57`：unusable runner ⇒ **`confine()` 抛 `SANDBOX_UNAVAILABLE`**。⇒ CVM 不会因 bwrap 缺失而 fail-open。

### ⚠️ 订正一条既有表述（属"声明过度"型）

原写「ABI 5+ 掩码喂 ABI 4 内核 ⇒ `create_ruleset` 直接 `EINVAL`」——该实测**成立**，但**主语是"人工喂高位掩码"**；**DSH 自身按协商 ABI 裁剪掩码，不会 EINVAL**。⇒ 不得读成「DSH 在 ABI 4 上会失败」。已在 `TODO.md` 与 `dsh-migration.md` 两处改写为精确表述。

### 工具层（本轮新踩，两条）

- **`ssh 'bash -s' < file` 跑的是非登录 shell** ⇒ `node` ／ `dsh` 在 PATH 里全空（**是场地事实，不是故障**）⇒ 探针一律用绝对路径或 `bash -lc`。
- **`core.autocrlf=true` 下 `git checkout -- <file>` 会把工作区还原成 CRLF** ⇒ 同一文件「我上次写的 LF」与「checkout 后的 CRLF」**行尾会变**。本仓库 `git ls-files --eol` 明示 **`i/lf w/crlf`** ⇒ **工作区规范 = CRLF**。教训：**写前必须重测行尾，不能沿用上一次读数**。
- 附带一条自查：脚本里跨行拼接把 `NL` 常量漏写成 `\n` ⇒ CRLF 文档被插入 LF 行。**因断言放在写盘之前**，未污染文件（`TODO.md` 那次）；但同批的 `dsh-migration.md` 已先落盘 ⇒ 只能 `git checkout` 还原重做。⇒ **批量写盘时，断言必须在每个文件写盘之前。**

### 3.4 的 token 上限（老大提问，已答）

判据原文 `dsh-migration.md:759`〈各切片判据细则〉S2 行：「…开跑前给 **token ／ 费用上限**」。语义 = **显式声明一个允许的预算上限**（**不是**"测 DSH 能跑到多少 token"）：S2 要逼出 compaction，须注入接近 `contextWindow`（实测 **1M**）的填充文本 ⇒ **单轮调用就是十万~百万 input token 量级**，故须事前圈定花费。⇒ 与本次 dry-run 无关（dry-run 零 LLM 调用，**未用任何 Key**）；到 3.4 正式开跑前才需老大给数。
